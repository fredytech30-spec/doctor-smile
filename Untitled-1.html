État réel de l'IA autonome actuelle Ce qu'elle fait vraiment : 3 règles de score (critique < 25, vigilance < 50, excellent > 85) → toast 1 écoute paiement échoué → toast Chat réactif pur : répond seulement quand on lui parle 4-5 recommandations statiques générées à l'analyse (mêmes textes pour tout le monde) Ce qu'elle ne fait pas du tout : Rien entre deux sessions utilisateur Rien sans que l'utilisateur soit connecté Aucune surveillance dans le temps Aucune action déclenchée automatiquement Aucune anticipation, aucune mémoire entre analyses Ce qu'un vrai agent IA autonome doit faire pour Doctor Smile Voici les 8 capacités concrètes à implémenter, par ordre d'impact réel sur la vie de l'utilisateur. 1. Surveillance continue des ratios avec seuils dynamiques Aujourd'hui : rien entre deux analyses. Ce qu'il faut : L'agent surveille en permanence via Firebase onSnapshot. Dès qu'une nouvelle analyse entre, il compare chaque ratio au précédent et déclenche une action contextuelle. Exemples concrets : - Current Ratio passe de 1.8 → 1.1 en un mois → Agent : "⚠️ Votre liquidité a chuté de 39 % depuis janvier. À ce rythme, vous passerez sous 1.0 dans 6 semaines. Action recommandée : [bouton → explication chat]" - ROA remonte de -2 % → +4 % après une recommandation → Agent : "✅ Votre rentabilité s'est améliorée suite aux ajustements. Le Dr Score a progressé de 12 points. [bouton → analyse détaillée]" 2. Pré-analyse automatique des fichiers importés Aujourd'hui : l'utilisateur importe, clique "Lancer ML", attend. Ce qu'il faut : Dès qu'un fichier est détecté, l'agent fait une pré-lecture intelligente avant même le ML. - Détecte automatiquement la devise, la norme (SYSCOHADA vs PCG) - Identifie les colonnes manquantes critiques et propose des corrections - Lance le ML en arrière-plan sans que l'utilisateur clique - Notifie "Votre analyse est prête" avec un résumé en 3 lignes 3. Rapport hebdomadaire automatique par email Aujourd'hui : aucun rapport automatique, rien n'est envoyé sans action utilisateur. Ce qu'il faut : Chaque lundi à 8h (Cloud Scheduler + Cloud Run), l'agent génère et envoie un rapport personnalisé. Contenu du rapport automatique : - Score actuel vs semaine précédente (variation + / -) - Les 2 ratios les plus dégradés de la semaine - Une recommandation prioritaire actionnable - Lien direct vers le dashboard Pas un email générique : "Bonjour Freddy, votre liquidité a baissé de 15 % cette semaine chez Kamdem Industries. Voici pourquoi et ce que vous pouvez faire." 4. Détection de tendances et alertes prédictives Aujourd'hui : alerte uniquement si un ratio est déjà mauvais. Ce qu'il faut : L'agent détecte une trajectoire avant que la situation devienne critique. Logique : - 3 analyses consécutives avec score en baisse → alerte prédictive - Calcul de la pente de régression sur l'historique des scores - Si pente < -5 pts/mois : "À ce rythme, vous entrerez en Zone Critique dans 8 semaines" - Suggestion proactive d'import d'une nouvelle analyse pour vérifier Exemple : Scores : [72, 68, 63, 57] → pente = -5 pts/mois Agent : "📉 Votre score decline régulièrement depuis 4 mois. Projection : Zone Risque dans 3 semaines. Importez vos données du mois de mars pour confirmer." 5. Simulation What-If automatique et suggestions chiffrées Aujourd'hui : le simulateur est manuel, l'utilisateur bouge des curseurs. Ce qu'il faut : L'agent calcule lui-même les scénarios d'amélioration les plus impactants. Après chaque analyse, l'agent simule automatiquement : "Si vous améliorez votre Current Ratio de 1.1 à 1.5 (en réduisant votre BFR de 18 %), votre score passerait de 52 à 71 — Zone Vigilance → Zone Saine." "Si vous réduisez votre endettement de 20 % sur 6 mois, votre Altman Z passerait de 1.4 à 2.1 — hors zone danger." Ces simulations sont affichées proactivement sans que l'utilisateur ait à manipuler les curseurs. 6. Mémoire inter-entreprises et benchmarking automatique Aujourd'hui : chaque analyse est isolée, pas de comparaison automatique. Ce qu'il faut : L'agent compare automatiquement l'entreprise à son secteur. - Dès qu'une analyse est créée, l'agent calcule le percentile sectoriel - "Kamdem Industries est dans le top 35 % des entreprises du BTP camerounais pour la rentabilité, mais dans les 20 % inférieurs pour la liquidité." - Benchmark automatique contre les peers anonymisés de Firestore - Si un concurrent sectoriel améliore son score de 15+ points, alerte discrète "💡 Les entreprises similaires dans votre secteur ont amélioré leur liquidité de 18 % ce trimestre. Voici comment." 7. Actions sur commande vocale ou message naturel Aujourd'hui : l'IA répond mais n'agit pas. Ce qu'il faut : L'agent peut déclencher des actions réelles sur commande. Commandes que l'agent doit comprendre et exécuter : "Envoie-moi le rapport de cette semaine par email" → Génère PDF + envoie email immédiatement "Compare mes 3 dernières analyses" → Lance automatiquement la vue comparateur et affiche les résultats "Alerte-moi si mon score descend en dessous de 60" → Crée une règle personnalisée dans Firestore, surveillance active "Planifie une analyse tous les vendredis" → Programme un rappel email hebdomadaire avec lien upload direct "Exporte toutes mes analyses du trimestre" → Génère un fichier ZIP avec tous les PDFs et l'envoie par email 8. Agent post-recommandation : suivi des actions Aujourd'hui : les recommandations sont marquées "fait" mais rien ne vérifie si elles ont eu un impact. Ce qu'il faut : L'agent suit l'exécution et mesure l'impact réel. - Quand une recommandation est marquée "fait", l'agent crée un checkpoint - Lors de la prochaine analyse, il compare les ratios concernés - "Vous avez appliqué 'Réduire le BFR' il y a 6 semaines. Résultat : votre BFR/CA est passé de 28 % à 21 %. Impact sur le score : +7 pts. ✅" - Si aucune amélioration : "La recommandation n'a pas encore produit d'effet. Voulez-vous l'approfondir avec l'analyste IA ?"
